Things I've built

Featured · Personal project

PayFlow: a payment backend that never loses a cent

A wallet and payment backend for deposits, peer-to-peer transfers and bank withdrawals, designed so money is never lost or double-spent under concurrency, crashes or attacks.

  • Idempotent API: a retried request returns the original result instead of moving money twice.
  • Atomic transfers: ordered row locks, a double-entry ledger and an outbox event in one transaction.
  • Event pipeline: outbox relay to RabbitMQ, exactly-once workers, retries and dead-letter queues.
  • Fraud & security: rule engine with auto-reversal and admin review, JWT rotation with theft detection, signed webhooks.
